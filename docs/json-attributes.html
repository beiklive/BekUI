0. 四类 JSON 文件

文件作用谁读
themes.json主题清单（有哪些主题可用）App / 设计器
<主题>/theme.json元信息 + files[] 显式清单（不扫目录）主题装载
<主题>/tokens/*.json色板（colors）与数值（metrics）主题数据
<主题>/base|widget/*.json外观：box + layers + states + transitionsAppearance::compile
<主题>/view/*.json视图描述：type + 属性 + children + includeViewTemplate
名字规则：相对主题根的路径去掉扩展名。base/button/button.json → 外观名 base/button/button；变体用后缀拼：base/button/button.primary。挪文件 = 改名，C++ 里的引用要一起改。

1. 取值语法

1.1 数字

写法含义例子
12像素（按 720p 设计稿写，运行时乘 uiScale）"width": 220
"50%"父容器主轴尺寸的百分比"width": "50%"
"auto"由内容/布局决定"height": "auto"
"@theme/metric.x.y"主题数值（自动带缩放规则）"radius": "@theme/metric.radius.md"
"&number.x"同文件 vars.numbers 变量"gap": "&number.gap"

1.2 颜色

写法含义
"#RRGGBB"6 位十六进制，不透明
"#RRGGBBAA"8 位，最后两位是 alpha
"@theme/color.a.b"主题色；key 不存在会编译失败（不静默回退）
"&color.x"同文件 vars.colors 变量
"transparent"全透明（等价 #00000000）

1.3 引用与变量

前缀作用域说明
@theme/主题取 color.* 或 metric.*；点号分层
&本文件引用本文件顶层 vars.colors / vars.numbers，不能跨文件
@i18n/视图描述取文案；实例化时替换（缓存模板不会烤死语言）
@icon/属性值图标名 → 字形，如 "icon": "@icon/star"
@res/资源路径相对 resources/，如 "src": "@res/img/a.png"
$键名元数据键（$comment / $files），装载器跳过；写在值位置会报错
{
  "vars": {
    "colors":  { "label": "@theme/color.text.primary" },
    "numbers": { "gap": 12 }
  },
  "box": { "gap": "&number.gap" },
  "layers": [
    { "op": "text", "id": "text", "data_id": "text", "fill": "&color.label" }
  ]
}

1.4 枚举

枚举值大小写与 _/- 都不敏感：flexEnd = flex_end = FLEX_END。视图 JSON 拼错 → 不建控件并报错（列出可选值）；外观 JSON 拼错 → 警告且保持原值。

2. 数值缩放规则

位置是否乘 uiScale说明
主题 metric.*✅metric.anim.*（毫秒）与 metric.font.lineHeight（系数）不缩放
外观 JSON 的 radius / strokeWidth / width / height / fontSize / inset / offset / feather / spread✅opacity 是系数、duration 是毫秒，都不缩放
视图 JSON 的像素量✅width / height / min* / margin* / top / left / right / bottom / borderThickness / cornerRadius / fontSize / 图片 offset
代码里写死的像素❌想跟随分辨率就用主题 token 或写进 JSON
// 720p 设计稿：uiScale = 画布宽 / 1280
// 1280 宽时 220 → 220px；2560 宽时 220 → 440px
"box": { "width": 220, "height": 300 }

3. 视图公共属性

所有视图（View）都支持；表格里标 px 的字段是像素量，会乘 uiScale。

键类型 / 取值说明
idstring调试/查找用；设计器选中靠它
typestring控件类型，如 Box / Label / Button；缺省 Box
childrenarray子节点
includestring引另一个视图 JSON（相对主题 root，需写 resources/views/... 的完整路径）
width / heightpx · "auto" · "50%" · @theme主轴尺寸
minWidth / minHeight / maxWidth / maxHeight同上尺寸夹取
grownumber剩余空间的分配权重（建议配 flexBasis: 0）
shrinknumber空间不足时的压缩权重；Yoga 默认 0 = 不缩
margin / marginTop / …px外边距
alignSelfauto|flexStart|center|flexEnd|stretch|baseline覆盖父容器的 alignItems
positionrelative|absoluteabsolute 不占流、不参与 gap
top / left / right / bottompx · %绝对定位偏移
visibilityvisible|invisible|gonegone 不占位、不参与布局
backgroundColorcolor盒底色（与外观层无关）
borderColor / borderThicknesscolor / px边框
cornerRadiuspx圆角
alpha0..1整棵子树的透明度（绘制期）
clipsToBoundsbool裁剪超出部分

4. Box 属性

键取值说明
axisrow|column主轴方向；默认 column
directioninherit|ltr|rtl文本/排列方向
alignItemsstretch|flexStart|center|flexEnd|baseline|auto交叉轴对齐
justifyContentflexStart|center|flexEnd|spaceBetween|spaceAround|spaceEvenly主轴分布
flexWrapbool是否换行
alignContentflexStart|center|flexEnd|stretch|spaceBetween|spaceAround多行时的行对齐
flexBasispx · % · autoflex 基准尺寸；0 + grow = 按权重分
gappx主轴间距
gapRow / gapColumnpx分别设行/列间距
padding / paddingTop / paddingRight / paddingBottom / paddingLeftpx内边距
{ "type": "Box", "axis": "row", "gap": 12,
  "children": [
    { "type": "Button", "text": "A", "grow": 1, "flexBasis": 0, "minWidth": 0 },
    { "type": "Button", "text": "B", "grow": 2, "flexBasis": 0, "minWidth": 0 }
  ] }

6. 外观 JSON 结构

顶层键类型说明
varsobject本文件变量：{ "colors":{}, "numbers":{} }，只有一个、必须在顶层
importstring / array引用其它外观并逐字段合并（当前文件优先）
boxobject盒模型/布局（见下节）
layersarray绘制层（必须有）
statesobject状态补间：focused / pressed / disabled / selected / on / off …
transitionsobject生命周期动画：enter / exit / show / hide
childrenarray外观驱动的子视图（可嵌套）
外观里没有的层 = 不画，这是正常情况；但 states/transitions 里引用不存在的层 id 会编译失败。删层时要把引用一起删。

7. 外观 box 段

键取值说明
axisrow|column控件内部排列方向（AppearanceView 默认 column）
width / height / minWidth / minHeight / maxWidth / maxHeightpx · auto · % · @theme尺寸
padding / marginpx 或 [上,右,下,左]只接受 1 个或 4 个数
gappx子项间距
grow / shrinknumberflex 权重
alignItems / justifyContent同 Box对齐
backgroundColor / borderColor / borderThickness / cornerRadiuscolor / color / px / px盒属性
measureContent"sum"固有尺寸按行求和（一行多内容层时用）

8. 绘制层属性表

键适用于取值说明
op全部rect|text|image|shadow|glass|custom层类型
id全部string层身份：状态键 layers.<id>.*、字体覆盖、设计器点选
data_idtext / image / customstring内容槽 id；省略时默认取层 id
font_kindtexticon|text字体种类；不写 = 正文字体
fill / color / textColorrect / shadow / textcolor底色、阴影浓度、文字色
stroke / strokeWidthrect / glass / shadowcolor / px描边；玻璃层里是内缘高光
radiusrect / shadow / glasspx圆角
opacity全部0..1层透明度（不缩放）
fontSizetextpx字号
align / valign全部left|center|right / top|center|bottom层在控件范围内的对齐
inset全部[上,右,下,左]向内收缩（可负值外扩），用于给图标让位等
offset全部[x,y]平移
width / height全部px显式尺寸（装饰件：色条 4 / 下边线 1）
feather / spreadshadowpx羽化与外扩
cutoutshadowbool只画外圈（挖空自身矩形）
innershadowbool内阴影（无方向，offset 无效）
scalingimagefit|fill|stretch|center图片缩放
tintimagecolor图片着色
gradientrectobject{type, angle, center, stops[2..4]}；优先于 fill
blurRadius / qualityglassnumber / enum玻璃模糊（总开关在 Shell）
{
  "box": { "width": 200, "height": 56, "cornerRadius": "@theme/metric.radius.md" },
  "layers": [
    { "op": "shadow", "id": "shadow", "fill": "#00000040", "feather": 12, "spread": 2 },
    { "op": "rect",   "id": "bg",    "fill": "@theme/color.surface.card", "radius": "@theme/metric.radius.md" },
    { "op": "text",   "id": "icon",  "data_id": "icon", "font_kind": "icon", "inset": [0,0,0,140] },
    { "op": "text",   "id": "title", "data_id": "text", "fill": "@theme/color.text.primary" }
  ]
}

9. states / transitions 通道

通道写法示例说明
layers.<层id>.<属性>"layers.bg.fill": { "to": "#7fd8ff" }层属性补间（fill/stroke/strokeWidth/radius/opacity/fontSize/inset/offset…）
translateX / translateY"translateX": { "to": 24 }整树绘制期位移（零重排，transitions 用）
scaleX / scaleY / alpha"alpha": { "from": 0, "to": 1 }整树缩放/透明度
字段说明
to必写，目标值
from可省，省略取当前值
duration毫秒；0 = 瞬变
easing如 cubicOut / easeInOut（大小写不敏感）
delay毫秒
when仅 transitions 层内条目：with / after
{
  "states": {
    "focused": { "layers.bg.fill": { "to": "@theme/color.highlight.background", "duration": 120, "easing": "cubicOut" } },
    "pressed": { "layers.bg.fill": { "to": "@theme/color.button.primaryPressedBg", "duration": 80 } }
  },
  "transitions": {
    "enter": { "translateX": { "from": 40, "to": 0, "duration": 220, "easing": "cubicOut" },
               "alpha":      { "from": 0,  "to": 1, "duration": 220 } }
  }
}

10. 完整例子

10.1 一张卡片

{
  "box": { "width": 220, "height": 300, "cornerRadius": 18,
           "borderThickness": 1, "borderColor": "@theme/color.common.divider",
           "backgroundColor": "@theme/color.surface.card" },
  "layers": [
    { "op": "rect", "id": "bg", "fill": "@theme/color.surface.card", "radius": 18 },
    { "op": "text", "id": "icon", "data_id": "icon", "font_kind": "icon",

  ],

    "focused": { "layers.bg.fill": { "to": "@theme/color.surface.hover", "duration": 120 } }
  }
}
