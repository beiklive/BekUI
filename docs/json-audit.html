一、语法完备性

1.1 五类文件，各管一段

1.2 三种引用前缀：@ 跨文件、& 同文件、$ 只做键

@跨文件引用

@theme/color.a.b · @theme/metric.a.b · @i18n/… · @res/…

指向别的文件；@theme/ 的 key 不存在 → 报错。

&同文件变量

&color.none · &number.radius

绑"写它的那份文件"的 vars；可链式（≤4 层），循环报错。旧写法 $color.x → 报错并提示改 &。

$只出现在键上

$comment 写注释 · $files 是 i18n 的补充文件清单

装载器按"跳过 $ 开头的键"处理；值位置不认。

1.3 完备性不是二值：闭合 / 半开 / 开放

1.4 五个已知不完备

问题严重度后果
视图未知属性只警告高 拼错的属性名能存能跑、静默忽略；"合法 JSON" 不可判定 attributes.cpp
theme.json 的 files[] 少了 .json高 该外观静默回退成空外观，只有一条警告
外观对 layers 以外的顶层键不敏感中 拼错 state / layer 不会被发现
colors.json 不支持 key 间引用中 语义色只能写字面量，改配色要一起改
数值有多种写法（12 / "12" / "50%" / @theme）低 做"原样回写"的工具必须保住原文，不能统一成 float

三、页面与控件的渲染

3.1 一帧的顺序：布局与绘制是分开的两段

  • 0字体　窗口创建后才可用；视图树通常更早建好
  • 1布局　只在脏时算、一帧最多一次（invalidate() 只置脏）
  • 1bUI 缩放　画布宽度变了 → 重新取外观 + 重排
  • 2动画与逐帧逻辑　滚动、动图、状态补间（AppearanceInstance）
  • 3输入与焦点　用上一帧的命中结果
  • 4业务回调　onUpdate 可能新建/改动视图树
  • 4b补一次布局　上面任何一步改了树，这里补算 —— 切页时文字不再堆在顶部
  • 5绘制视图树　root->frame(drawList) 递归；层按已排好的顺序画
  • 6玻璃采集　GL：首个 glass 命令时抓帧一次（半分辨率模糊 + 折射）
  • 7ImGui 窗口　宿主自己的面板：视图树之后、ImGui::Render() 之前

3.2 层序是解析期定死的，不是书写顺序

3.3 控件 → 层 → 注册表分派

AppearanceView::frame取当前 AppearanceInstance
→
逐层遍历已按 sortLayers 排好
→
op → 注册表LayerDrawContext 分派
→
layer_draw_*rect / text / image / shadow / glass / custom / EXTENSION
为什么分派走注册表：加一种 op = 解析字段 + registerLayer<T>() 带一个 draw 钩子， 上层不用改；第三方层（stripe / quad）就是这么接进来的。

3.4 同一个 JSON 键，落到哪一步

JSON编译产物绘制位置
box.*AppearanceBox（已乘缩放）写进 Yoga 节点，布局期生效

layers[i].inner / cutout布尔选 drawSoft / drawInnerSoft

transitions.*视图级 + 层内通道（delay 已折算）TransitionPlayer：绘制期变换，零重排
vars / & / @theme解析期就消失无（运行时看不到引用）
import合并后的 Appearance无（运行时看不到来源）

四、重做设计器前要补的三个接口

模型源文档 + 有效值并列

import/include/vars 让"文件"≠"对象"。需要保留键序、未知键、原始写法（"50%"、&color.x）的结构模型，外加"合并后有效值 + 每个字段来自哪份文件"。

引用能解但不丢引用

现在 json_vars 是就地展开、展开即消失。工具要能显示"指向哪里 + 解析后的值"，同时保留 & 本身。

校验视图侧严格模式

未知属性目前只警告 → 工具无法判定"合法"。需要一个 strictAttributes 开关（报错而非警告，默认关）。

五、建议（前三条都是"让错误更早暴露"）

#建议成本收益
1视图侧加 strict 模式（未知属性报错，默认关）小让"合法 JSON"可判定
1b错误恢复策略（已实现）：JsonErrorPolicy = STRICT / SKIP_FIELD / FALLBACK_DEFAULT + 诊断表完成容错但不静默：恢复过的错误都留 file/path/message
2theme.json 的 files[] 少后缀：警告 → 报错小避免"外观静默变空"
3外观顶层键白名单小拼错 state/layer 能被发现
4把"结构模型"抽成库（保序 / 原文 / 来源）中重做设计器的地基，也方便写校验工具
5json-syntax.md 补两处：$=元数据、EXTENSION 参数表从哪查很小减少误用
