# 设计器界面样板房（HTML）

**这一版是按用户口述要求重画的**（扁平风格 / 只留菜单栏 / 图标化 / 分 Tab / 整块画布）。

对着它确认设计意图，不用真跑程序：

```bash
open designer/mockup/index.html        # macOS；或直接拖进浏览器
```

导成图片（给手机上看 / 存档）：

```bash
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless=new \
  --disable-gpu --hide-scrollbars --force-device-scale-factor=1.5 --window-size=1470,900 \
  --screenshot=/tmp/mockup.png "file://$PWD/designer/mockup/index.html"
```

样板房表达的约定（改界面之前先看这几条）：

| 位置 | 约定 |
|---|---|
| 顶栏 | **只有菜单栏**（文件/编辑/视图/工具/帮助）。`打开项目` 在「文件」里；不再有第二行按钮；右侧只显示 项目 · 当前文件 · 未保存圆点 |
| 左栏上 | 文件列表**按类型分 Tab**：控件 / 页面 / 主题表，每条目带图标 |
| 左栏下 | 节点树：开关（展开全部 / 只到层 / 只看层）收在标题**右侧用图标**；节点数配图标；层行只有名称 + 类型徽标 + 字段数，**行内没有按钮** |
| 中间 | **整块就是画布**（棋盘打底），控件直接画在上面；状态竖排钉在左边缘、视图开关竖排钉在右边缘（画布平移缩放不影响）；底部一行显示 分辨率 · 倍率 · 路径 |
| 右栏 | 属性按类别分组（尺寸 / 外观 / 布局 / 颜色 …），**标签与取值一律中文**；不放增删按钮、不放"改动 N 处" |
| 操作 | 层/字段的复制、删除、增加层、增加字段都在**右键菜单**；**上下移 = 直接拖动**（有插入位置指示线） |

图标在样板房里用内联 SVG（不依赖字体）。实现时改用 borealis 的 material icon 字体，
并保证图标与文字**纵向对齐**（按行高取中，不能偏高）。
