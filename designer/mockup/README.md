# 设计器界面样板房（HTML）

**这不是程序，是界面样板**：用浏览器打开 `index.html` 就能看到设计器的四块布局和交互，
点树、改属性、看 diff 都是真的能点，但数据是假的、不会写任何文件。

用途：动手写 C++ 之前先对齐界面理解。

```bash
open designer/mockup/index.html                     # 外观文件（按钮）
open 'designer/mockup/index.html?file=page_home'    # 页面视图（整页预览）
open 'designer/mockup/index.html?file=dialog'       # 带 shadow 的弹窗
```

看这几处：

| 区域 | 对应需求 |
|---|---|
| 左上 文件列表 | 可编辑文件（主题外观 / 页面视图 / 主题表），● = 未保存 |
| 左 节点树 | 逐层展开：文件 → box / 每一层 / states → 每状态 → 每通道；带层号 #1 #2 |
| 中 预览区 | **选中什么渲染什么**：控件外观 / box 段 / 单层 / 状态 / 整页视图 |
| 右 属性表 | 按节点类型给表单；改完预览立刻变；颜色与数字能从主题 key 挑 |
| 左下 节点数 | 节点 / 层 / 状态统计 + 当前节点路径 |
| 顶栏 | 新建项目（模板新建 / 直接编辑）、保存（diff 确认）、还原、另存、画布尺寸/背景/缩放 |

不在样板里的（等真做）：真实的编译校验、写盘与 `.bak`、热重载、层增删排序的实际接线。
